# R Client

Mobile-first Roblox **Rivals** client for Delta. Sticky head aimbot, silent aim, ragebot,
triggerbot, ESP, movement, 54 modules and a client-side skin changer with 18 skins.

Site: https://njjjjjhij.github.io/r-client/

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/njjjjjhij/r-client/main/RClient.lua"))()
```

## Files

| File | Purpose |
| --- | --- |
| `RClient.lua` | the whole client, single file |
| `index.html` | landing page, comparison table, download |
| `assets/style.css` | page styles |
| `assets/app.js` | copy-loadstring button |
| `assets/r-logo.jpg` | hero logo |
| `assets/ui-panel.svg` | interface shot |

## Controls

| Input | Action |
| --- | --- |
| Tap the R badge | open / close the panel |
| Insert | open / close the panel |
| Right Shift | panic, everything off |
| Hold Q / E / R / C | aimbot / silent / rage / trigger |

Everything is client-side: no remote calls, no inventory changes, no server writes.
The skin changer is visual only, so other players never see it.
Using cheats in public matches breaks Roblox's rules and can get your account banned.
