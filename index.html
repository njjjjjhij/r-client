Anti-cheat reality

Nothing to see on the server side.

Client-side by design

R Client is a Lua userscript inside Delta. It never fires a remote, never edits inventory, never writes game state the server reads, and never touches the network layer. Aim is camera-only, ESP is local drawing, skins are local repaints.

That means there is no server-side footprint from gameplay data for the game to roll back or flag — no ammo changes, no speed packets, no teleports sent by the script itself.

It is not a guarantee. Roblox can detect injected code client-side, and every executor carries its own risk. Use an alt, expect bans, and treat the account as expendable. R Client does not claim to be undetectable and does not sell a bypass.

FAQ

Straight answers.

Does the aimbot really stick to the head?

Yes. The target bone is the Head by default, and sticky mode keeps the locked player for the persistence window (0.4s default) before it can switch. The smoothing filter is exponential, the turn is rate-clamped and there is no random offset, so it tracks without the shiver most mobile aimbots have.

Do other players see my skins?

No. The skin changer repaints parts on your client only. The server never receives a skin change, so your inventory and everyone else's view stay untouched.

Does it work on Delta mobile?

Yes. The panel is built for touch: the corner badge, the category rail and draggable sliders all work without a keyboard. Insert and RightShift still exist for PC.

Why is silent aim different from aimbot?

Aimbot moves your camera, which you can see. Silent aim leaves your view alone and only rotates the camera for the instant the attack remote is called, then restores it before the frame renders.

Can I get banned?

Yes. Cheating in Rivals breaks Roblox's rules. R Client is client-side and avoids the usual server-side tells, but no client can promise safety. Use an alt.
